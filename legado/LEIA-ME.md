# Versão do endereço antigo (koda.gamersite.workers.dev)

Enquanto os dois endereços ficam no ar, o servidor entrega no endereço antigo esta cópia congelada do site
(a versão que estava no ar quando o kodagb.com começou), com uma única diferença: o `<script id="koda-migracao">`,
que entrega o login e os dados pro kodagb.com quando ele pede. As novidades vão só pro `index.html` da raiz (kodagb.com).

Quando o endereço antigo for desligado, esta pasta pode ser apagada (e as linhas do "endereço antigo" em servidor/index.js e wrangler.toml).
